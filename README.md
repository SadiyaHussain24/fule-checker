# ⛽ Smart Fuel Checker
A sleek, responsive web tool designed to help users instantly calculate trip costs and fuel consumption. Built completely from scratch using HTML, CSS, and JavaScript.

Features:
. Clean UI/UX: Modern card layout with intuitive input fields for distance, mileage, and fuel price.

. Instant Calculations: Powered by JavaScript to compute results dynamically.

. Fully Responsive: Adapts seamlessly to different screen sizes.
